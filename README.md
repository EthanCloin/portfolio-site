# ethancloin.xyz

Personal site: a hand-written homepage plus a blog at `/blog` that is built with
[Astro](https://astro.build) and fed from an Obsidian vault.

- `public/` — the homepage (`index.html`, `style.css`, `assets/`), copied to the site root verbatim.
- `src/` — the blog: layout, pages, RSS (`/blog/rss.xml`), sitemap, Open Graph tags.
- `src/content/blog/*.md` — published posts. Generated by the publish script; edit the note in the vault instead.
- `scripts/publish/` — Obsidian note → post converter and PR opener (see `.claude/skills/publish/SKILL.md`).
- `scripts/server/` — droplet setup/status scripts run through the *Server (manual)* GitHub Actions workflow.
- `docs/` — how Obsidian Sync runs on the droplet, how to point an agent at the vault, and the publishing section for the vault's `CLAUDE.md`.

## Develop

```bash
npm install
npm run dev        # http://localhost:4321  (homepage at /, blog at /blog)
npm test           # publish script unit tests
npm run build      # renders to dist/; CI checks dist/index.html is byte-identical to public/index.html
```

The homepage's Tailwind CSS is precompiled and committed. To regenerate it after editing `public/index.html`:
`npm run tailwind:homepage`.

## Publish a post

Give the note `status: ready`, `slug`, `date`, `description`, `tags` in its frontmatter, then:

```bash
npm run publish-note -- "My Note" --dry-run   # preview
npm run publish-note -- "My Note"             # write, build, branch, push, open PR
```

or `/publish My Note` from Claude Code. Merging the PR deploys.

## Deploy

`.github/workflows/deploy.yml` builds on every push to `main` and rsyncs `dist/` to the droplet.
